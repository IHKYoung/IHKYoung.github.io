一、请填写 BOOL , float, 指针变量 与“零值”比较的 if 语句。(10 分)#

提示:这里“零值”可以是 0, 0.0 , FALSE 或者“空指针”。例如 int 变量 n 与“零值” 比较的 if 语句为:

if ( n == 0 )
if ( n != 0 )

以此类推。

请写出 BOOL flag 与“零值”比较的 if 语句。（3 分）#

//标准答案
if ( flag )
if ( !flag ) 
// 如下写法均属不良风格，不得分。
if (flag == TRUE)
if (flag == 1 )
if (flag == FALSE)
if (flag == 0)

注解：BOOL值直接用if判断即可，没必要出现==的情况。
